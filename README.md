### 🏁 ゲームの目的

全員が1回ずつ「親」を担当した後、**最終的な所持金（Dウォレット）が最も多いプレイヤーが勝利**です。


### 🔄 ゲームの流れ（1ラウンド）

親を1人決め、以下の手順で進めます。

#### 1. 親のゲートイン

* 親コマをスタート地点に置きます。
* **全員が100ドッチ（通貨）を受け取ります。**

#### 2. 予想タイム（賭け）

全員が「ドッチ券」2枚に記入して賭けます（最低10ドッチ〜上限なし）。

* **子プレイヤー（親以外）**
* 親が**どのマス（ゴール）にたどり着くか**を予想して賭けます。


* **親プレイヤー**
* **どの子プレイヤーが予想を的中させるか**を予想して賭けます。



#### 3. 親の出走（正解発表）

* 親はピラミッド状の質問カードに対し、YESかNOで答えながらコマを進めていきます。

#### 4. 結果判定・配当
* **的中した場合:** マスの倍率に応じた配当金を受け取ります。
* 親の予想が当たった場合の配当は常に2倍です。


---

### 🛑 ゲームの終了

親が「ソウルメイトの段（ゴール）」まで進んだらラウンド終了です。質問カードをすべて入れ替え、左隣の人が次の親になります。
**全員が親を行ったらゲーム終了**です。

### 💻 PC版の遊び方

ボードゲーム「どっちぼーい」（ClaGla）を、PCやスマホで遊べるようにしたものです。

#### はじめ方

* `docchi-boy.html` をブラウザで開くだけで遊べます。インストールやサーバーは要りません。
* プレイヤー名（3〜6人）を入れて、使う質問セットを選び、「ゲームスタート」を押します。
* 予想タイムでは、画面の案内に従って端末を順番に回し、ほかの人に見られないように賭けます。
* 出走中に答えを押し間違えたら「1つ戻す」で取り消せます。
* 途中でページを閉じても、タイトル画面の「前回の続きから」で再開できます。

#### 盤面と倍率

* 質問は毎ラウンド、選んだセットからランダムに15問が並びます。
* YESなら左下、NOなら右下へ進みます。
* 賭けられるのは3段目から下です。
  * 知人の段（3段目）×2 ／ 友達の段（4段目）×3 ／ 親友の段（5段目）×4
  * ソウルメイトの段：端から ×16・×12・×8・×12・×16

#### 質問の編集

* タイトル画面の「質問セット」→「編集する」で、画面上で質問を追加・修正できます（1行に1問）。
* 「ノーマル」と「恋愛」のセットが最初から入っています。新しいセットも作れ、複数のセットを混ぜて遊べます。
* txtファイル（1行に1問）の読み込みと書き出しができます。`questions_nomal.txt` と `questions_love.txt` は内蔵の質問の元データです。
* 編集した内容はそのブラウザに保存されます。別のブラウザや端末には引き継がれないので、残したいときはtxtで書き出してください。

#### スマホ・タブレット

* 縦長の画面でもチャートが崩れないようにしてあります。出走中はYES/NOのボタンが画面の下に固定されます。
* 1台の端末を回して遊ぶ想定です。各自のスマホから同時に参加する仕組みはありません。

#### iPad・スマホでオフラインで遊ぶ

GitHub Pages で公開しています： https://aeeiouuuu.github.io/docchi-boy/

1. ネットに繋がっているときに、上のURLを Safari で一度開きます。
2. 共有ボタン →「ホーム画面に追加」を選びます。
3. 以後はホーム画面のアイコンから、ネットが無くても起動できます。

* iPadの「ファイル」アプリでHTMLを直接開くと、プレビュー画面ではボタンが動かないことがあります。上の方法を使ってください。
* ホーム画面から起動したアプリと Safari では、保存される質問セットや途中データが別々になります。
* `docchi-boy.html` を更新したときは、`sw.js` の `CACHE` の番号（`docchi-boy-v1` など）を上げてください。ネットに繋がったときに新しい版へ入れ替わります。

#### 公式ルールから省いたもの

* **スペシャルチップ**：配当の倍率を上げたり、質問を入れ替えたりするチップは使いません。
* **ヒントタイム**：出走前に子が質問を1枚ずつ選んで親に聞く時間はありません。

どちらが無くても、十分に読み合いを楽しめます。
